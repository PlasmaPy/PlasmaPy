Other Useful Projects
=====================

The following projects and resources complement PlasmaPy and may be useful
for researchers working with Python in heliophysics and related fields.

Python in Heliophysics Community (PyHC)
---------------------------------------

The `PyHC Documentation Hub`_ provides a centralized way to search
documentation for Python packages used in heliophysics.

.. _PyHC Documentation Hub: https://heliopython.org/pyhc-docs/
